# 抽卡式作者品味校准（Taste Calibration）

通用规则只能保证"不 AI 味"，做不到"像这个作者"。本技能用真实选段校准出作者的个人口味，并让 AI 在下一轮主动收敛。

## 核心闭环

```
抽卡（结构不同的候选）
  → 作者选段标注（哪里好/哪里坏，低负担）
  → 取具体证据（落到哪一句、哪个动作、哪段对白）
  → 更新「作者偏好档案」
  → 下一轮按档案收敛
```

## 〇、工作台已经把这条闭环做成按钮了（0.2 起）

装了 dsh-novel-craft 的话，不用再手工在会话里跑：章节页「✍️ 开新章」四步就是本技能的全部流程——
要方向 → 一次一篇写候选（落进 `factory/runs/<作品>/第N章/候选稿/`）→ 去抽卡选段（顺手写一句取用原因）
→ 合并成定稿并写入正文。合并只拼作者选中的段落，跨稿接不上的地方留成 `〔此处需过渡〕` 标记，
交给批注式微调处理。**本技能剩下的部分讲的是"怎么把这四步做好"**：

## 一、抽卡：候选要"结构不同"，不是"换词"

- 同一组核心事实下，变化的是**叙事决策**（视角、物件母题、对白驱动、留白、喜感、信息差、空间距离……），不是形容词。
- 每轮先列出 8–10 个"写法差异"方向（如：保守精修 / 配角识药 / 主角算计 / 对手戏 / 轻喜剧动作 / 生活流 / 反转 / 道具对照 / 最少对话 / 纯外部镜头），再逐篇落笔。
- 十篇同质文本比一篇还糟；宁可少几篇，也要保证每篇决策不同。

## 一·五、规律要能追到证据（工作台已实现）

每条规律都该能回答"凭什么"。工作台的做法：提炼时把标注原文编号喂给模型，要求每条规律末尾写
`（来自 3、7）`；采纳后落进 `规则来源.json`，界面上点规律后面的「🔍 证据」就能看到那几段原文。
模型没标编号时，工作台会用词面重合度兜底**并明确标成"推测"**——宁可说这是猜的，也不要假装它来自模型。

老档案（提炼时还没记编号）可以点「补齐来源」：一次很便宜的模型调用，把规律与编号后的原文一起给它，
只让它指出对应关系。判断对不对，作者点开就能核。

对写 skill 的启示：规律要写得**能被证据支撑**（说做法，不说评价），否则来源对不上，作者也就没法否决它。

## 二、作者选段标注（低负担）

- 让作者只看"好/坏"两类反馈，或直接点选喜欢的段落，不要求写评语。
- AI 主动追问时，一次只问一个最关键的问题，给可点选项（含"你决定"）。
- 便宜的模型用来筛候选（标题/摘要/差异说明），作者选定方向后，贵的模型才写完整正文。

## 三、取具体证据，不抽象

作者说"这段好"，必须落到"哪一句、哪个动作、哪段对白"。禁止把反馈翻译成"更细腻""更高级"这类空话。

例（真实案例）：作者说"K 版好，但有几处我更喜欢"，证据是——
- "苏清鸢绕到马鞍左侧抬脚踩了踩马镫，又换到右侧重复一遍"（具体笨拙动作）
- "宁陈提醒再往前会影响马喘气"（用一句干巴巴的话接住）

这些证据直接写进偏好档案，成为下一轮改稿的靶子。

## 四、更新「作者偏好档案」

每轮选段后，把**能影响后文**的偏好追记进一份持久档案（建议 `作者偏好档案.md`），结构：

```
## 已验证偏好（作者喜欢什么）
（每条配一个具体引文证据）
## 避免的写法（作者不喜欢什么）
（每条配一个具体反例）
## 本轮新增证据
（本轮选段 + 为什么）
```

记不下、影响不了后文的细枝末节不记。AI 评审与作者选择分开记录，**作者偏好拥有最终权重**。

## 五、下一轮收敛

- 下一轮不再发散，按偏好档案收敛（如：原文骨架 + 某版的人物心理 + 某版的删减尺度 + 某版的关键处留白）。
- 合并片段必须重建因果，禁止机械拼接：喜欢 A 的某段 + B 的某段 ≠ 整块复制，要让前后因果自然生长、节奏重排。

## 六、盲评分离，作者定权

- 多个子代理独立盲评（禁止看写法映射、禁止互相讨论），再和作者的对答案。
- 实测教训：AI 评审偏爱"结构完整、技巧集中"，作者偏爱"有生命力、连载语感、人物原有气息"，两者会分歧——**必须以后者校准**，不能拿 AI 评审当作者。

## 七、归档不删除

原稿进"未采用原稿"，候选进对应章节候选稿；正式稿被替换时旧稿归档。过程证据永远保留。

## 八、成本控制

便宜模型（flash 档）做追问 + 候选摘要 + 盲评初筛；贵模型（V4 / GLM4.5）只做定稿正文。相同步骤、模型、输入命中缓存不再请求。
